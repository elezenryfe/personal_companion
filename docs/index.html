Built to stay out of the way

A little context, right where you need it.

Ryfe brings a few useful parts of your development workflow into one compact interface.

Local repositories

See your projects, branches, working-tree changes, diffs, and repository status.

GitHub pull requests

Keep track of pull requests you opened and reviews waiting for you, including CI status.

Gmail

View recent inbox message details, archive messages, mark them as read, and create drafts. Ryfe does not send email.

AI assistant

Ask questions about your work with an assistant that can use supported read-only tools and propose changes for your approval.

Ryfe is a locally installed Windows application. Its source code is public; integrations are configured by the person using the app. Review the source and the privacy policy before connecting accounts.
